# Gerenciador de Tarefas em Java

## Visão Geral
Este é um sistema simples de gerenciamento de tarefas desenvolvido em Java. Ele permite a adição, listagem, atualização, exclusão e filtragem de tarefas por status.

## Status do Projeto
🚧 **Em desenvolvimento** 🚧  
O código ainda contém alguns erros e melhorias estão sendo planejadas. Em versões futuras, será incorporado um banco de dados para armazenamento persistente das tarefas, bem como uma interface gráfica para interação mais amigável.

## Funcionalidades
- Adicionar novas tarefas com título, descrição, data de criação e status.
- Listar todas as tarefas registradas.
- Atualizar o status de uma tarefa existente.
- Excluir uma tarefa por ID.
- Filtrar tarefas por status.

## Melhorias Planejadas
- ✅ **Correção de bugs** para garantir uma experiência mais estável.
- 🔗 **Integração com banco de dados** para persistência de tarefas.
- 🎨 **Desenvolvimento de um front-end** para melhor usabilidade.
